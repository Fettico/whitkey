# 纯白键道 · WhitKey

基于 [星空键道6](https://github.com/xkinput/KeyTao) 的 Rime 音形输入方案。

纯白键道是星空键道6的**次级方案，而非升级版**。保留原有的编码体系与 Phrase 词库，通过短码保留、候选钉选、自动拆码和逐字组词等功能，让输入法在日常使用中逐渐贴合个人习惯。

## 核心特色

### 候选顺序，自己决定

输入时追加形码，如果原来的首选仍然匹配，纯白会将其保留在后续候选中，而不是直接丢弃。

配合 `Ctrl+P` 钉选，可以将常用词放到自己习惯的编码上，而不需要修改原始词库。例如，星空词库中有：

| 词语 | 原编码 |
| --- | --- |
| 试试 | `ekek` |
| 实施 | `ekeko` |
| 实时 | `ekekoo` |

如果更常用「实时」，可以将它钉选到 `ekek`；原来的词也可以通过追加形码继续选择。同一编码只保留一个钉选词，再次按下 `Ctrl+P` 即可取消。

### 缺词不用手动查表

纯白支持自动拆码与逐字组词。词库没有的双字词，可以直接从候选中逐字选出，输入法会学习这次组合。

例如输入 `lghq`，候选中有「零花」却没有「灵化」，仍然可以依次选择「灵」「化」组成词语。之后再次完整选中「灵化」，便会记录为个人自组词；需要时也可以进一步钉选。

逐字选字时还能追加形码，减少重码。对于不便逐字组出的长词或中英混合词，则可以使用 `U` 键自造词。

### 沿用成熟词库，不必从头维护

纯白直接使用星空键道的 [Phrase 词库](https://github.com/xkinput/KeyTao/blob/master/rime/keytao.phrase.dict.yaml)。大词库方便，但每个人常用的词并不相同；与其反复删改原词库，不如通过钉选、隐藏和自动组词调整自己的候选。

更新 Phrase 词库时可以直接替换相应文件。个人的钉选、隐藏、自组词及自造词记录独立保存，不必跟随词库反复修改。

## 快捷功能

| 按键 | 功能 |
| --- | --- |
| `Ctrl+P` | 钉选或取消钉选当前候选 |
| `Ctrl+Q` | 隐藏当前编码下的候选；对自造词、自组词执行删除 |
| `Tab` | 快捷上屏当前候选页的首个英文词条 |
| `A` | 输入自定义短语，适合常用文本与固定内容 |
| `I` | 输入快捷符号、拉丁扩展字母与 Emoji |
| `U` | 自造词，支持多字词及中英文、数字混合内容 |
| `V` | 快速输入英文、数字和标点，无需切换输入模式 |
| `O` | 计算器、日期时间、数字转换、笔画反查、输入统计与花体英文 |

例如，输入 `wkfk` 后按 `Tab`，可直接上屏当前候选页的英文词 `WiFi`；输入 `iqj` 可查询「猪」对应的 Emoji。

## 细节优化

- **自动调频**：两码候选优先考虑单字，曾经选过的单字可以在较短编码下更容易找到，而无需调整静态词库。
- **自定义 630**：默认不预设统一的 630，方便在熟悉自己的输入习惯后自行配置；也支持开启强制 630。
- **四音码两分反查**：使用两个字的音码查找拆分字，例如 `nlww` 可查询「妫」。
- **死码拦截**：误输入不存在的编码时，避免后续按键导致错误上屏或吞码，便于及时发现并修改。
- **唯一候选数字上屏**：部分入口只有一个完整候选时，可直接追加数字，例如 `qio3` 上屏「正常3」，省去一次空格。
- **候选显示可定制**：候选图标、编码旁注、功能开关及部分符号列表都可以按需调整，另扩充了部分生僻字。

## 安装与配置

将仓库中的方案文件放入 **Rime 用户配置目录**，重新部署后选择「纯白键道」。

- `whitkey.custom.yaml`：常用功能开关与显示设置。
- `white_replace/`：钉选、隐藏、自组词、自造词等个人记录，可单独备份和迁移。
- `A_纯白功能说明.txt`：完整功能介绍、操作示例与注意事项，详见 [纯白功能说明](A_纯白功能说明.txt)。

**注意**：包内的 `default.custom.yaml` 会将方案列表设置为只显示纯白键道；`weasel.custom.yaml` 属于小狼毫全局界面设置。已有其他方案或自定义皮肤的用户，请按需合并，避免直接覆盖原有配置。
